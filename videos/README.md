# Application video

## Automated Risk Analysis

The application connects maintenance work order import, MacBERT–MGP fault knowledge extraction, hierarchical fault knowledge graph visualization, and maintenance risk analysis in an interactive workflow.

**Supplementary Video S1 — in preparation.**

The video covers:

1. Importing maintenance work orders and reviewing the input records.
2. Extracting subsystem, component, and failure mode labels.
3. Exploring the radial hierarchical fault knowledge graph.
4. Selecting Top K fault paths and comparing occurrence counts, cost severity, economic burden, and balanced risk.
5. Tracing ranked paths to supporting work orders and exporting the analysis results.
